# Custom fonts (optional)

This directory is flashed to LittleFS (`/littlefs/fonts`). It ships the Roboto
set generated by `scripts/generate_fonts.bat` (sizes 10/12/14/16/18, regular +
bold), covering ASCII + Cyrillic.

```
roboto_10.bin        roboto_10_bold.bin
roboto_12.bin        roboto_12_bold.bin
roboto_14.bin        roboto_14_bold.bin
roboto_16.bin        roboto_16_bold.bin
roboto_18.bin        roboto_18_bold.bin
```

The on-device UI falls back to the built-in LVGL Montserrat fonts (Latin only)
when a `.bin` is missing. To use a different typeface, generate an LVGL binary
font with the LVGL font converter and drop the resulting `*.bin` files here;
the firmware loads them with `lv_font_load("S:/fonts/<name>.bin")`.

Converter: <https://lvgl.io/tools/fontconverter>

Note: the **web** configurator is already multilingual (RU/EN) — see
`data/web/locales/`. This note only concerns the fonts drawn on the device
screen.
